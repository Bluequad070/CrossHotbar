# CrossHotbar Forever

## v1.0.2
First release on CurseForge.

## v1.0.0
First public release.

- FFXIV-style cross hotbar for WoW: Forever's gamepad UI
- LT, RT and LT + RT sets that share slots with Blizzard's gamepad bar, so the normal spellbook / bag **Bind** flow fills them
- Double-tap LT or RT for the x2 flyouts (face buttons); one press snaps back to the main set
- Adjustable double-tap window
- Blizzard's native gamepad button art, round face-button icons, trigger and button glyphs (Xbox / PlayStation)
- Button styles: Native, Classic, Minimal, Flat
- Dimmed idle groups with native-style shadows; "Edit" prompt while holding LT + RT
- Controller-friendly settings window (hold LT + RT and press View, or /xhb)
- Drag & drop: pick up a spell or item with the spellbook or bags open and every set appears as a drop target, with a glow on the button you're over
- Steps aside while the spellbook, bags, character or profession windows are open so Blizzard's own bind flow works untouched
